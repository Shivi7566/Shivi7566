## 🚀 About Me

I am a Senior Identity and Access Management (IAM) Engineer with **7.5+ years of enterprise experience** securing hybrid cloud environments across **Microsoft Entra ID, Okta, AWS IAM, and Oracle Cloud IAM**. 

Currently leading IAM delivery across global enterprise accounts at **DXC Technology**, specializing in:
- **Zero Trust Architecture:** Conditional Access policies, Continuous Access Evaluation (CAE), Risk-based step-up auth.
- **Identity Governance & Administration (IGA):** Joiner-Mover-Leaver lifecycle workflows, entitlement management, and PIM.
- **Enterprise Federation & Provisioning:** SAML 2.0, OIDC, OAuth 2.0, SCIM provisioning, and app registrations.
- **Hybrid Identity Synchronization:** Microsoft Entra Connect, Cloud Sync, Password Hash Sync (PHS), and Pass-Through Auth (PTA).
